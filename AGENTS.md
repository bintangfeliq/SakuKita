\# SakuKita Project Instructions



\## UI/UX Design



When working on any frontend, UI, UX, layout, styling, or visual design task:



1\. Read `.agent/skills/ui-ux-kit/SKILL.md` before making changes.

2\. Read the relevant reference files inside `.agent/skills/ui-ux-kit/references/`.

3\. Analyze the existing SakuKita project before changing the UI.

4\. Keep the design consistent across all pages.

5\. Prefer a clear, intentional visual direction over generic AI-generated UI.

6\. Avoid unnecessary gradients, excessive rounded cards, excessive shadows, excessive decorative elements, and random visual effects.

7\. Prioritize hierarchy, spacing, typography, contrast, usability, and responsive behavior.

8\. The interface must work properly on desktop, tablet, and mobile.

9\. Use Bootstrap 5 and the existing project technology unless there is a strong reason not to.

10\. Do not modify backend logic when the task is only about frontend UI/UX.

11\. Do not create unnecessary files or duplicate components.

12\. Before implementing a redesign, explain the proposed visual direction and structure first when appropriate.



\## Project



SakuKita is a personal finance application.



Main frontend direction:



\- Java

\- Spring Boot

\- Thymeleaf

\- Bootstrap 5

\- HTML

\- CSS



The UI should feel like a real financial application: clean, trustworthy, modern, practical, and professional.



Do not make the interface look like an obvious AI-generated template.
